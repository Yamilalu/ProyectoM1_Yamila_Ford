Uso de Inteligencia Artificial

Durante el desarrollo del proyecto utilicé Inteligencia Artificial como herramienta de apoyo para resolver dudas, revisar aspectos del desarrollo y realizar mejoras.

Las respuestas obtenidas fueron probadas directamente en el proyecto antes de incorporar cambios.

La documentación de las consultas realizadas, sus resultados y las evidencias correspondientes se complementa con el registro del proceso realizado durante el desarrollo.

Aclaración sobre los prompts

Los prompts incluidos en esta documentación corresponden a consultas realizadas durante el desarrollo del proyecto. 

Prompt — Visualización en modo celular desde la computadora

Reconstrucción del prompt utilizado:

«“Chati, cuando abro mi proyecto en la computadora no puedo verlo como si fuera la pantalla de un celular. Quiero comprobar cómo se ve la página en el celular, pero no sé cómo hacer para verlo desde la computadora. ¿Me ayudás?”»

Resultado:

La IA explicó cómo utilizar las herramientas del navegador para visualizar la página en diferentes tamaños de pantalla y comprobar el diseño responsive sin necesidad de abrir el proyecto directamente desde un celular.

Cómo influyó en el proyecto:

Esto permitió realizar pruebas de visualización en distintos tamaños de pantalla y comprobar que la aplicación se adaptara correctamente a dispositivos con pantallas más pequeñas.


otro prompt
Corrección del centrado del footer

Situación:

Después de agregar el footer al proyecto, el texto no quedaba centrado correctamente.

Consulta realizada a la IA:

Le indiqué a ChatGPT que el footer no se estaba centrando y compartí el código CSS que estaba utilizando para revisar el problema.

Resultado:

Se revisó el CSS y se modificó la regla del footer para asegurar que el texto quedara centrado:

footer {
    width: 100%;
    text-align: center !important;
    margin-top: 20px;
}

Cómo influyó en el proyecto:

La corrección permitió que el texto del footer quedara centrado correctamente en la página.

Prueba realizada:

Después de guardar los cambios, se comprobó el resultado en la aplicación publicada mediante GitHub Pages y el footer quedó centrado.
