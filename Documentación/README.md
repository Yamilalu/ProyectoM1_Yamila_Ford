Colorfly Studio 🎨

Generador de paletas de colores

Colorfly Studio es una página web que hice para generar paletas de colores de una manera fácil y rápida.

La idea es que puedas elegir cuántos colores querés y, al tocar el botón, se genere una paleta al azar.

Podés elegir entre 6, 8 o 9 colores.

🌐 Demo online

Podés probar el generador de paletas desde este enlace:

https://yamilalu.github.io/ProyectoM1_Yamila_Ford/Desarrollo/index.html

¿Qué se puede hacer?

- Elegir la cantidad de colores.
- Generar una paleta nueva al azar.
- Ver cada color en una tarjeta.
- Ver el código HEX de cada color.
- Generar una nueva paleta cada vez que se presiona el botón.
- Ver un mensaje que confirma que la paleta fue generada.
- Usar la página desde distintos tamaños de pantalla.
- Tener algunos efectos al pasar el mouse por las opciones, el botón y las tarjetas.

¿Cómo funciona?

Primero se elige la cantidad de colores: 6, 8 o 9.

Después se presiona el botón “Generar paleta”.

JavaScript genera colores al azar y los muestra en tarjetas. Cada tarjeta muestra el código HEX correspondiente.

También aparece un mensaje que confirma la cantidad de colores generados.

Cómo fui haciendo el proyecto

Fui armando el proyecto por partes.

Primero hice la estructura en HTML, después trabajé el diseño con CSS y finalmente agregué la funcionalidad con JavaScript.

Durante el proceso fui probando que funcionara la generación de las paletas de 6, 8 y 9 colores. También probé los efectos al pasar el mouse y el diseño responsive. También realicé pruebas de navegación con teclado.

Además, utilicé inteligencia artificial como herramienta de apoyo en algunas etapas del proyecto. Fui haciendo consultas, probando los cambios y decidiendo cuáles incorporar. La documentación específica del uso de IA forma parte de la documentación de la entrega.
